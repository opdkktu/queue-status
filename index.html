📲 Panduan & Status Notifikasi

Memeriksa...
    ID peranti (untuk staf):—

    Ujian 5 saat menyemak sama ada telefon ini boleh memaparkan notifikasi — tekan, kemudian tukar ke apl lain atau kunci skrin. Untuk ujian penuh (dari pelayan klinik), staf boleh hantar mesej ujian kepada ID peranti di atas melalui OneSignal.

    1. Buka pautan PRIMA dalam Chrome (bukan dalam WhatsApp / Facebook — tekan ⋮ → Buka dalam Chrome).
    2. Tekan ⋮ (menu Chrome) → Pasang apl atau Tambah ke skrin utama. Atau tekan butang Pasang Apl di atas.
    3. Buka PRIMA dari ikon di skrin utama.
    4. Masukkan nombor giliran → Semak Status → tekan Benarkan apabila diminta kebenaran notifikasi.
    5. Penting: Tetapan → Apl → Chrome (atau PRIMA) → Bateri → pilih Tanpa sekatan / Unrestricted. Matikan mod Jimat Bateri.
    1. Perlu iOS 16.4 atau lebih baharu. Buka pautan PRIMA dalam Safari (bukan Chrome / aplikasi lain).
    2. Tekan ikon Kongsi ⎙ → tatal → Tambah ke Skrin Utama → Tambah.
    3. Tutup Safari. Buka PRIMA dari ikon di skrin utama (bukan dari Safari) — notifikasi hanya berfungsi dari sini.
    4. Masukkan nombor giliran → Semak Status → tekan Allow / Benarkan.
    5. Penting: Tetapan iPhone → Notifikasi → PRIMA → pastikan dibenarkan. Matikan mod Fokus / Jangan Ganggu semasa menunggu.
    ❓ Notifikasi tidak muncul?
    • Pastikan semua tanda di bahagian status di atas berwarna ✅.
    • Pastikan nombor giliran sudah dimasukkan dan status giliran dipaparkan.
    • Jangan force-close / buang apl dari senarai apl yang dibuka (terutama Android).
    • Pastikan internet atau data mudah alih aktif; jangan hidupkan mod penjimat data yang menyekat apl latar.
    • Jika kebenaran pernah ditolak: buka Tetapan telefon → Notifikasi → PRIMA / Chrome → Benarkan, kemudian tekan Semak Semula.
    • Masih gagal? Padam ikon PRIMA, pasang semula mengikut langkah di atas, dan beritahu kaunter pendaftaran.
